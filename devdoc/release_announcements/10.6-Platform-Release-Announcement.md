# HPCC Systems 10.6.0 Platform Release Announcement

HPCC Systems 10.6.0 is here, delivering a faster, smoother, and more productive platform experience.

This release combines focused code refactoring and bug-fix work with meaningful runtime and UI improvements, so teams can move from development to production with greater confidence.

## Performance Improvements

### Roxie Runtime

- 36815 (Roxie): Boosts data-path efficiency with allocator specialization for send and receive operations.

## Notable Changes and Features

### ECL Watch Usability

- 36569 (ECL Watch): Introduces Workunit Compare and streamlines WorkunitDetails for faster root-cause analysis.
- 36451 (ECL Watch):  Adds File Summaries on demand, helping users quickly understand workunit outputs.
- 36699 (ECL Watch):  Improves visibility and clarity of Workunit Errors/Warnings where users need them most.

### Refactoring and Stability

- Includes broad refactoring and bug-fix investment to strengthen maintainability, reliability, and everyday operational resilience.
